## How To Use

1. Start with `notes/CONFORMANCE_LEDGER.md` for the current status.
2. Open the relevant `notes/IR_*.md` file for the implementation contract.
3. Use the linked `*_ASM_FACTS.md` file when a rule needs address-level proof.
4. Do not promote PNG-fit probes into implementation unless the IR says the
   rule is binary-grounded or AE exact for the exact slice.

  only, unless a row explicitly says 16/32bpc.

  Mac AE exact behavior unless a binary/runtime proof shows the AE path is also
  wrong.

  `trace-too-sparse` placeholders should update the ledger as evidence, not the
  implementation contract.
