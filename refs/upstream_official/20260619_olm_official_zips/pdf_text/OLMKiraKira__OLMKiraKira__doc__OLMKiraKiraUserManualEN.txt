1. Introduction
OLM KiraKira is an effect plugin that can generate glowing effects from a picture highlights.
Simple sparks and glowing effect is generated by combining vertical, horizontal and
diagonal blur from the highlights alpha, luminance or RGBA channels.

3. OLM KiraKira parameters
OLM KiraKira parameters are as follows:
OLM KiraKira parameters
● Channel
You can choose between 4 channels to generate the glow effect.
（Default is Alpha）
- Alpha: Use the alpha channel of the input
- Luminance: Use the luminance of the input
- RGB: use RGB+alpha
- Brightness: use the biggest value of the R, G or B channel

● Blur Mode
Specify the type of blur (default is Approximated Gaussian). Box is fast but not as
smooth as Gaussian. Choose a mode according to the look and rendering time you
target.
- Box: a simple box blur
- Approximated Gaussian: approximates Gaussian with box blur
- Gaussian: typical Gaussian blur
- Exponential: long tail blur

● Merge Mode
Composite mode between an input layer and generated glow
- add: weighted sum with alpha value
- premultiply: weighted average with alpha value
● Approximated Input
When on, the input resolution will be reduced to accelerate rendering time while
producing a more blurred result (default is off). Turn on or off according to the look and
rendering time you target.
● Brightness Gain
Intensity of the glow. The slider shows value from 0 to 200, but values up to 1000 can
be set (default is 1).
● Threshold (Strength Multiplier)
Threshold the input according to the Channel mode. Only the values above the
threshold value will be processed (default 0%, which means that the every pixel of the
input will be processed)
● Fade Out
The fade out parameter is used when the Channel used is either Brightness or
Luminance. It will smooth especially the effect of the Threshold parameter.
● Glow Opacity
the opacity of the glow effect (default is 100)
● Source Opacity
the opacity of the input layer (default is 100)

● Vertical Color
The vertical glow color (default is white)
● Vertical Color Ramp
The vertical glow color ramp
- Use Ramp: Check it to use a ramp instead of a single color

● Horizontal Length※
The horizontal glow length. Slider can be set from 0 to 200, but values can be set up to

The horizontal glow color (default is white)
● Horizontal Color Ramp
The horizontal glow color ramp
- Use Ramp: Check it to use a ramp instead of a single color
- Ramp: Ramp color control
● Diagonal Length※
The diagonal glow length (when glow rotation is 0, add glow on 45 and 135 degrees
directions). Slider can be set from 0 to 200, but values can be set up to 1000 (default is
0)
● Diagonal Color
The diagonal glow color (default is white)
● Diagonal Color Ramp
The diagonal glow color ramp
- Use Ramp: Check it to use a ramp instead of a single color
- Ramp: Ramp color control
● HighLight Radius※
The radius of the highlight glow. Slider can be set from 0 to 200, but values can be set
up to 1000 (default is 0)
※ When Vertical, Horizontal, Diagonal Length or HighLight Radius are set to 0, the
corresponding process will be skipped. If you don’t need that effect, then just set the
value to 0.
● Highlight Color
the highlight glow color (default is white)
● Glow Rotation
the glow orientation in degree (default is 0)
