OLM Toon Dilate Manual
Introduction
Dilates non-transparent image regions towards their transparent borders.
Release notes
Version Date Notes

Usage
With OLM Toon Dilate you can expand the color towards transparent pixels. A little bit like the Minimax effect of
After Effects, but simple to use in Japanese animation production.
In production it's very useful to add specific taste to outlines of a drawing while setting the color under the line to
something coherent with the drawing. Start with a drawing, key the outlines and then apply OLM Toon Dilate as
shown below.

Parameters
OLM Toon Dilate is a very simple effect. It just has one parameter:Search Radius.
Search Radius determines the amount of dilation in pixels. The following image shows the plugin applied to an
image with search radius 0px (the original image), 4px and 8px.
