1. Introduction
OLM Blur is an After Effects plug-in that applies blur to not fully transparent pixels
(alpha>0). Using OLM Color Key together, this plugin enables users to blur only boundary
between specified colors.
Figure 1 (Left) Original Image, (Middle) After Gaussian Blur in Adobe After Effects
(Right) After OLM Blur with OLM Color Key (Keeping effect)

2. Using OLM Blur
To apply the effect, use the menu: (Effects)→(OLM Plug-ins)→(OLM Blur)
3. OLM Blur parameters
OLM Blur parameters are as follows:
Figure 2 OLM Blur parameters
● Blur Amount: Determines the coverage of blur. Value go from 1.0 to 100.0. With big
amount and smoothness the blur is applied in wider area.
● Blur Smoothness: Determines the smoothness of blur. Value go from 1.0 to 100.0.
Big value of smoothness result in stronger blur.
● Number of Repeat: Determines the number of iteration of blur. Value go from 0 to 10.
Larger the number of repetitions results in smoother result with less artifacts. The
rendering cost also increases with the number of repeat.
● Bias Direction: Determines the bias direction of the result. Vertical or horizontal is
selectable. Please see the Fig. 3 for the difference between two modes.
