1. Introduction
Distance Gradation is a plugin for Adobe® After Effects® (AE). It will generate gradation
inside/outside of mask (alpha channel). It can then be used to create aura or light effects.
Also by using black and white gradation inside a mask, it produces depth map that could be
used for 2D/3D conversion.
Figure 1 Example of uses of Distance Gradation
1.1. Supported Environment
Please refer to OLM Open Tools website for a complete list of supported environment.

3. Distance Gradation Parameters
Figure 2 Distance Gradation parameters
● In/ Out －The gradation can be generated in three different regions (Figure 3)
● Inside － Inside the mask
● Outside － Outside the mask
● Both －Inside and outside the mask
Figure 3 In/out gradation mode comparison (from the left: inside, outside, both)
● Inside Threshold － The threshold to use when the gradation is generated inside
the mask. It defines the maximum distance to generate gradation to (Figure 4).
With a small value, the inner part of the mask gets flat and will generate an
emboss like gradation.
● Outside Threshold －The threshold to use when the gradation is generated
outside the mask. It defines the maximum distance to generate gradation to.

With small values the overall pictures get dark.
● Render Mode － We can choose between the three following rendering mode
(Figure 5).
RGB － Generates a colored picture from the distance. At 0 distance from the
mask, Gradation Color will be used, at the maximum distance, Background color
will be used. In between, color will be computed according to the interpolation
method chosen.
Layer － Use the color from the input image to generate gradation
Figure 5 The different render mode (from left: RGB, Layer)
● Use Background Color － When off, alpha gradation of the Gradation Color is
generated. When on, alpha channel is generated with a value of 1, and BG Color
is used to generate the color gradation.
● Gradation Color － The color of the gradation
● BG Color － When Use Background is ON, is used for the background color.
● Invert －When Use Background is OFF, will invert the alpha channel, resulting in
transparent alpha close to the mask and opaque alpha far from it. When Use
Background is ON, will invert the Gradation Color and BG Color.

● Interpolation Mode － There is 3 interpolation mode (Figure 7, Figure 8)
Linear－Linear interpolation
Sphere－Interpolate with a sphere-round shape
Power －Interpolate with power function. Uses Power parameter to create
sharp shape( Power >1), and round shape (Power <1).
Constant －Fill-up with color without interpolation
● Power －This parameter is valid only when Interpolation Mode is Power. Adjust
the interpolation shape.

● Blur Mode － Defines what kind of blur is applied at post process (Figure 9)
No Blur － no blur applied
Blur No Scale－ simple blur
