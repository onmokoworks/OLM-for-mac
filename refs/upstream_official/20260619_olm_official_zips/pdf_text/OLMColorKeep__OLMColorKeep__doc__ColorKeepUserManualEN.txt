OLM Open Tools Color Keep User Manual
1. Introduction
Color Keep is an effect plug-in for Adobe® After Effects® (AE). The Color Keep effect
affects the alpha channel of a given image by keeping only the given color lists (the inverse
of color key).
Figure 1 (Left) Original Image, (Right) Example where cap color are used in Color
Keep

2. Using Color Keep
To apply the effect, use the menu: (Effects)→(OLM Plug-ins)→(Color Keep).
When you apply Color Keep the layer becomes black.

● Enabled Color Num－Choose the number of color you want to choose. By increasing
this parameter, the number of “Color” parameter increase. You can increase it up to
100.
● Color－Choose the color you want to “keep”. The default is RGB= (0, 0, 0). That’s why
at first application of the effect you will have the impression that nothing is selected. To
select a color, you will have to first disable the effect once, pick the color and re-enable
the effect.
